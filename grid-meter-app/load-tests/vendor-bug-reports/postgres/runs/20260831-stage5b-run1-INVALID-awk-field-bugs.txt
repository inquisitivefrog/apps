broken.

Script bugs, both in the first draft of
load-tests/postgres-consul-nonleader-agent-loss-test.sh:
1. `awk '$3=="leader"'` used the wrong field index against
   `consul operator raft list-peers`'s output (Node ID Address State ...)
   -- State is field $4, not $3. Result: "Raft leader: " printed empty.
2. `awk -F'|' '$5'` used the wrong field index against `patronictl list`'s
   pipe-delimited table (| Member | Host | Role | State | TL | ...) -- TL
   is field $6, not $5. Result: "Baseline timeline: running" (printed the
   State column's value instead of the real TL number).
