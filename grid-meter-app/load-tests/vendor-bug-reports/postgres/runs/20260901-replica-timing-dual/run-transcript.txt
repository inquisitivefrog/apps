RESULT: 3 seconds for BOTH replicas simultaneously -- identical to the single-replica case,
not slower. This directly refutes a "dual simultaneous bootstrap contends for the primary's
resources" explanation for the original fresh-bootstrap test's >60s result. The original
run's replicas joined immediately after a full Consul KV wipe and patroni-1's own concurrent
bootstrap -- a "everything cold and settling at once" condition this controlled test did not
reproduce (Consul was already stable/mature throughout this test). That remains a plausible,
untested hypothesis for the discrepancy, not a confirmed one. The original run's actual
duration was never precisely measured, since its own poll gave up at 60s rather than
continuing to an exact number.
